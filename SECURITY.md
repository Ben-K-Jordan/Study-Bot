# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Open a private advisory at
[github.com/Ben-K-Jordan/Study-Bot/security/advisories/new](https://github.com/Ben-K-Jordan/Study-Bot/security/advisories/new)
(Security tab, then "Report a vulnerability"). Include the steps to reproduce
it and what an attacker could do with it.

Once a fix ships, the advisory is published with credit to you, unless
you'd rather stay anonymous.

## Supported versions

Only the latest commit on `main` gets security fixes.
